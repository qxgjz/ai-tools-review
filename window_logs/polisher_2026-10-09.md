## 重要发现（工具 bug）

**`scripts/batch_zensink_final.py` 存在严重 bug**:
- 第 41 行把所有 HTML 标签 `re.sub(r'<[^>]+>', '', content)` 全部剥掉再写 .md 文件
- 但 zens-ink content_qc 对 .md 文件检测的是 markdown 语法（`## 标题`、`[text](url)`、YAML frontmatter）
- HTML 被剥后，h2 变成纯文本、`<a href>` 链接丢失、frontmatter 不存在
- 结果：145 篇里 133 篇被误判不及格，实际用 .html 扩展名重测后质量远高于此

**建议后续修复**:
- 把 batch_zensink_final.py 改成写 .html 文件（zens-ink 会走 HTML 解析器直接读原始标签）
- 或在写 md 前把 HTML 转 markdown（h2→##, a→[text](url), ul→-）
