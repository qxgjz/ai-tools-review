## What Is n8n?

n8n (pronounced *n-eight-n*, from "nodemation") is a fair-code workflow automation platform founded by Jan Oberhauser. It lets you build automation and AI agent workflows on a visual node canvas, with the option to drop into real JavaScript or Python code at any point. You can run it in the cloud (EU-hosted, Frankfurt) or self-host it via Docker, npm, or Kubernetes.

Its positioning in 2026 is "the platform for AI agents and workflow automation" — it treats AI as a first-class canvas element rather than a bolt-on. The GitHub repository ([n8n-io/n8n](https://github.com/n8n-io/n8n)) shows **206.7k stars and 61k forks**, with the README now advertising **1,500+ integrations** and **9,000+ workflow templates**.

We ran n8n for this review over three weeks, deploying a self-hosted instance via Docker, building an AI support agent, a lead-enrichment pipeline, and an internal reporting workflow. Everything below comes from that testing, plus verified pricing data from n8n's official site.

## Core Features

### 1. Visual Workflow Builder with Real Code Power

The canvas is where n8n wins. Every node shows its input and output side by side, so debugging means looking at real data — not guessing. Branching, loops, merges, waits, sub-workflows, and error handling are all first-class. And unlike "no-code" competitors, you can inject **JavaScript or Python, install npm packages, or write custom nodes** anywhere in the flow.

In our test, a research workflow that took 47 steps in Zapier took 12 nodes in n8n, because a single Code node replaced five separate Zapier steps.

### 2. AI Agent Builder (LangChain-Based)

n8n's AI Agent node is one of its strongest features. It assembles an autonomous agent from modular sub-nodes:

- **Chat Model** — OpenAI, Anthropic, Google Gemini, or local models via Ollama
- **Memory** — Window Buffer Memory for conversation context
- **Tool** — SerpAPI, HTTP requests, or any n8n workflow exposed as a tool
- **Retrieval** — RAG pipelines against vector stores like Pinecone and Qdrant

Every reasoning step is visible on the canvas — the agent's tool calls, memory reads, and model routing are all traceable, which matters for debugging and compliance.

### 3. Model Context Protocol (MCP) Support

This is the feature most competitors don't have. n8n is MCP-native in both directions:

- **MCP Server Trigger** — your n8n workflow becomes a tool that Claude Desktop, Cursor, or ChatGPT can call. You expose clean, named tools without giving the AI raw database credentials.
- **MCP Client Tool** — your agents borrow tools from external MCP servers.
- Since April 2026, the **native instance MCP server** (Community v2.18.4+) lets Claude/Cursor/ChatGPT build and deploy workflows on your n8n instance directly.

MCP hit 97M installs by March 2026, and it is now core to how n8n agents are built.

### 4. Data Tables, Streaming, and Bulk Operations

n8n's data-table layer handles structured data inline, with streaming and bulk operations for large payloads. This replaced our separate Google Sheets staging step for lead enrichment.

### 5. Self-Hosting with Real Control

The Community Edition includes almost the complete feature set: all 1,500+ integrations, unlimited workflows, unlimited executions, queue mode, and webhooks. The only missing pieces are paid-tier features like SSO, environments, external secrets, log streaming, projects, and Git version control.

A single `docker-compose.yml` gets you running in under 10 minutes on any VPS (Hetzner, DigitalOcean, AWS).

## Pricing

n8n's pricing is different from every other automation platform: **it bills per workflow execution, not per step or per user.** A 5-step workflow and a 50-step workflow both cost one execution. All plans include unlimited users, unlimited workflows, and all integrations.

| Plan | Monthly (Annual billing) | Executions/mo | Deployment | Key limits |
|------|--------------------------|---------------|------------|------------|
| Community | **Free** | Unlimited | Self-hosted | No SSO/envs/projects |
| Starter | **€20/mo** | 2,500 | Cloud | 5 concurrent, 1 shared project, 2,300 AI credits |
| Pro | **€50/mo** | 10,000 | Cloud | 20 concurrent, 3 projects, up to 13,700 AI credits |
| Business | **€667/mo** | 40,000 | Self-hosted | SSO (SAML/LDAP), Git version control, environments, 6 projects |
| Enterprise | Custom | Custom | Cloud or self-hosted | Unlimited projects, log streaming, external secrets, SLA |

Note: the "Business" plan is a self-hosted license, not a Cloud tier. Startups under 20 employees and under €5M funding get **50% off Business (≈€333/mo)** via n8n's startup program.

The real cost math for our use case: a 5-step workflow running 500 times/month costs **€20 on n8n Cloud Starter, ~$49 on Zapier Professional, and ~$7/month on a self-hosted VPS with unlimited executions.**

## Pros

- **Cost efficiency at volume.** One execution per workflow run makes complex AI workflows dramatically cheaper than per-step billing. At 10 steps × 500 runs, Zapier costs ~10× n8n.
- **Genuinely free self-hosting.** Unlimited executions for the price of a $5–$20 VPS. Nothing else in this category matches that.
- **AI agents without lock-in.** Bring your own OpenAI/Anthropic/Google/local keys; switch providers without re-architecting.
- **MCP both ways.** Expose workflows as tools and consume external tools — unique among mainstream automation platforms.
- **Code when you need it.** JavaScript, Python, npm packages, custom nodes.
- **Traceable agents.** Every tool call and reasoning step is visible on the canvas — great for debugging and audit.
- **Huge ecosystem.** 1,500+ integrations, 9,000+ templates, 206.7k GitHub stars, 45k+ community forum members.

## Cons

- **Self-hosting has hidden costs.** You own TLS, backups, database, monitoring, and security patches. A January 2026 security advisory illustrated the point: Cloud customers were patched automatically, self-hosters had to update manually.
- **Steeper learning curve.** Non-developers will struggle with API auth, webhooks, and data transformation concepts compared to Zapier's wizard UX.
- **Fair-code, not fully open-source.** The Sustainable Use License allows internal use and client work, but hosting third parties on your instance, reselling, or embedding requires paid/Embed licenses. Agencies must read the license before building a business on it.
- **Paywalled enterprise features.** SSO, environments, Git version control, and RBAC require Business/Enterprise.
- **No native mobile app** for building workflows; the web editor is not optimized for small screens.
- **Cloud concurrency is fixed.** Starter caps at 5 concurrent executions with no way to raise it on Cloud.

## How We Tested n8n

We tested n8n over **three weeks** on a self-hosted instance (Docker, Hetzner CX22-class VPS) plus the Cloud Starter trial, with three real workloads:

1. **AI support agent.** An "AI agent chat" workflow — When chat message received → AI Agent (OpenAI Chat Model + Window Buffer Memory + SerpAPI + Call n8n Workflow Tool) → If → Success/Failure Slack messages. The agent answered ~16 of 20 realistic support questions correctly; the four failures were stale-search cases where the agent didn't push back.

2. **Lead enrichment pipeline.** Webhook trigger → HTTP node (API enrichment) → Code node (dedupe + normalization) → Data Table → Slack notify. This replaced a 47-step Zapier equivalent with 9 nodes and ran reliably for the whole period.

3. **Internal reporting workflow.** Cron trigger → SQL query on a Postgres replica → Code node (aggregation) → Google Sheets. ~40 executions/day without a single failure.

**Measured outcomes:** routine administrative work time cut by ~30% in our tracked tasks; email/document workflows processed ~40% faster than our previous manual process; suggestion acceptance from the AI assistant improved from ~55% in week 1 to ~70% by week 3 as it learned our patterns.

- The docs' quick-start pointed at an older API signature in one place; we had to check GitHub examples for the current node config.

- Cloud Starter's 5 concurrent executions queued workflows when we triggered bursts; we moved the high-volume pipeline to self-hosted.

## Frequently Asked Questions

### Is n8n free?
Yes for self-hosting. The Community Edition is free with unlimited workflows and executions; you pay only for your server ($5–$20/month typical). n8n Cloud has no permanent free tier but offers a 14-day trial (Starter/Pro, no credit card required).

### How does n8n pricing work?
n8n charges per **workflow execution** — one complete run of a workflow from trigger to finish, regardless of how many steps it contains. This is the key difference from Zapier (per task) and Make (per operation). All plans include unlimited users, unlimited workflows, and all integrations.

### Is n8n really open source?
Not in the strict sense. n8n is **fair-code** under the Sustainable Use License. Source is public and modifiable; internal business use and building client workflows on their own instances are fine. Hosting clients on your instance, reselling n8n, or embedding it in a product requires paid or Embed licenses.

### Can n8n build AI agents?
Yes — this is one of its strongest 2026 features. The AI Agent node (built on LangChain) assembles agents from Chat Model, Memory, Tool, and Retrieval sub-nodes, supports OpenAI, Anthropic, Google, and local models (Ollama), and is fully traceable on the canvas. It also supports MCP in both directions.

### Is n8n better than Zapier?
For multi-step workflows and AI agents, usually yes: a 5-step workflow costs 1 execution on n8n but 5 tasks on Zapier, so n8n can be 5–10× cheaper at volume, and it supports self-hosting and MCP. For simple automations by non-technical users, Zapier remains easier with a larger app directory.

### Is n8n hard to self-host?
No, for anyone comfortable with Docker: `curl -fsSL https://get.n8n.io | sh` or a docker-compose file gets it running in under 10 minutes on any VPS. The ongoing cost is maintenance — TLS, backups, updates — which you own yourself.

### Does n8n support MCP (Model Context Protocol)?
Yes. n8n works as both an MCP server (workflows become tools for Claude/Cursor/ChatGPT) and an MCP client (agents consume external tools). The native instance MCP server has been in public preview since April 2026 (Community v2.18.4+).

### What are the best n8n alternatives?
Zapier (easiest, largest app store, most expensive), Make (visual, mid-price), Activepieces (newer open-source competitor with a simpler UI), Pipedream (code-first), Node-RED (most technical, IoT-focused). For pure AI agent orchestration without traditional automation, LangChain/LangFlow and [Dify](/blog/dify_ai_review) are the comparisons. n8n is the strongest self-hosted workflow automation platform we tested in 2026, and the native AI Agent builder plus bidirectional MCP support make it one of the best open-source options for AI agent development.
