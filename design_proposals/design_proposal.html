03 · 设计系统

Token 一览（design_standard v1.0）

所有页面组件必须取这些 token，禁止拍脑袋取值。

🎨 色彩

  • 强调色 #5E6AD2
  • 背景 #fff→#fafafa→#f4f4f5
  • 文字 rgba(0,0,0,.9/.6/.45)
  • 边框 rgba(0,0,0,.08) hover .12
  • 状态 done #10B981 / progress #F59E0B / cancel #EF4444
  • 禁用 #3b82f6 默认蓝

🔤 字体

  • 标题 Space Grotesk 600
  • 字距 -0.5~-2.4px
  • 正文 Inter 16px / 1.5
  • 权重仅 400/500/600

📐 布局

  • 8pt 网格
  • section 留白 80–120px
  • 卡片 gap 16 / 24px
  • max-width 1200px
  • Bento ≤8 卡/区
  • 圆角 8–12px

⚡ 动效 & 质感

  • 100 / 150 / 250ms
  • easing cubic-bezier(.16,1,.3,1)
  • 4% SVG 噪点 overlay
  • 阴影即边框
  • hero 真实截图 1.2x

06 · 路线图

分阶段实施

每阶段改完必须本地预览截图 → 用户确认 → 才部署。

Phase 1 · 本周

设计系统 + 首页

  • shadcn 体系接入（已本地完成）
  • 首页 hero 真实截图 + bento（已本地完成）
  • 强调色全线切 #5E6AD2（已本地完成）
  • 待用户确认后部署
Phase 2 · 下周

工具页 + 文章页

  • 评分卡 6 维可视化
  • 正文排版统一（16px/1.5）
  • 表格/引用/代码块规范
  • Top10 流量工具页先改
Phase 3

全站收敛

  • 自写组件→shadcn 替换
  • 动效/噪点全覆盖
  • 暗色模式校准
  • 间距统一 80–120px
Phase 4

新功能

  • 工具筛选器
  • 收藏夹
  • 对话式导购
  • 性能/无障碍达标

推荐：方向 A（Clarity · Linear 极简）

理由：1) 与"专业评测"定位最匹配——克制、可信、SaaS 级；2) 与 design_standard 标准值完全一致，改动最小、落地最快；3) 对比类内容（表格/评分）在浅色极简下可读性最佳；4) Linear/Vercel 风格在 AI 工具站中已被证明转化友好。

取舍：方向 C（Vivid）更有记忆点但偏离"权威评测"气质、圆角 16px 超标准；方向 B（Contrast）冲击力强但深色 hero 与广告位/联盟披露兼容性略差。A 为主、可吸收 C 的状态色徽章作为点缀。
