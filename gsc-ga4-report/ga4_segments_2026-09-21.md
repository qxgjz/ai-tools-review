## 六、GA4机器人过滤说明

GA4自带的"排除已知机器人和蜘蛛"过滤（基于IAB/ABC列表）**默认已开启，且无法通过API关闭或修改**。但它的局限是：
- 只过滤声明自己是爬虫的UA（如Googlebot）
- 伪造浏览器UA的bot（Puppeteer、Cloudflare节点、安全扫描器）全部穿透

**建议操作（需手动在GA4 UI中完成）：**
1. Admin → Data Streams → aitoolcrux → Configure tag settings → Show all → **Define internal traffic**：添加你自己的公网IP
2. Admin → Data Settings → Data Filters → 创建新filter：排除新加坡IP段（如果确认是固定来源）
3. **更实际的做法：** 在GA4报告中创建Segment，只看"互动会话"（engaged sessions），忽略bot
